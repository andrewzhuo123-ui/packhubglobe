# What should a repeat-order quote carry over from the first order?

I can reorder the same box by name and receive a quote based on the old artwork, a different board, or a fresh tooling charge.

**I carry over the last approved structure, artwork, materials, sample and acceptance criteria. I ask the supplier to confirm what it will reuse and show current prices, order limits, dates and any proposed changes separately.**

I start with the version that was accepted in production. Then I compare the new quote with that baseline and check every difference before releasing the order.

## Which specification should I send with the reorder request?

The first quote can describe a design that changed during sampling. I look for the last approved record before I request a price.

**I send the approved item code, structural drawing, artwork revision and material specification. I include the sample reference and any correction accepted before the previous production run.**

### I start from the version we actually used

I check the last delivery and find the specification that applied to it. If the original carton had a narrow glue flap and the production version used a wider one, I send the approved revision that shows the wider flap. I identify the actual finish and stock. If someone accepted a different material for a single delivery, I record whether that approval ended with the lot. I avoid turning a temporary exception into the default by copying the most recent invoice alone.

Esko describes how a structural design file can hold the cut and crease lines separately from the graphic design.[^1] I identify both files and the approved combination. I also retain a photograph of the formed sample when it helps show orientation or a small construction detail. I use the [dieline preparation guide](/guides/prepare-packaging-dielines/) when I need to explain how the files should be handled.

I include the checks that mattered on the first order. If the packer measured a particular panel or compared a finish under agreed lighting, I repeat that requirement in the reorder request. I check which items still use the same specification. A product family can share a name while carrying several packaging sizes and graphics. I give each one its own line so the supplier can confirm the correct combination.

## What should I confirm about tooling and retained samples?

A previous tooling charge does not tell me which tool is available today. I ask the supplier to check its records before it prices the reorder.

**I confirm the tool reference, condition and intended reuse. I ask the supplier to identify any repair, replacement or setup charge and explain what the new order will require.**

### I match the physical tool to the approved structure

I give the supplier the earlier order and tool identifiers. I ask it to confirm that the tool still exists and that its drawing matches the carton I am ordering. I check whether anyone modified it for a later product. If the original run included a separate finishing tool, I confirm that item too. A die can be ready to use while the finish needs a different setup. I ask the supplier to show those charges separately.

I also ask whether the retained reference sample matches the last accepted delivery. If the supplier still has a sample made before a correction, I ask it to set that one aside. I use the [print proof approval record guide](/blog/packaging-print-proof-approval-record/) to keep the accepted sample and production revision visible. If the supplier cannot identify the sample or the material has changed, I agree on what needs to be checked before the order runs.

I ask which routine setup charges still apply even when a tool is reused. I also ask what happens if the tool needs work after inspection. If repair could change the carton, I request a representative sample and specify what it needs to demonstrate. I record the decision against the quote so it can be checked before production begins.

## Which commercial terms should I ask the supplier to quote again?

A familiar product can come with a different order minimum, a changed delivery schedule or another freight arrangement.

**I ask for current quantity breaks, unit price, setup charges, delivery terms and lead time. I compare them with the earlier order using the same quantity and cost scope where possible.**

### I make differences easy to trace

| Quote field | What I ask the supplier to show |
| --- | --- |
| Quantity | Current minimum and pricing for my planned order |
| Unit price | Included materials, assembly and packing |
| Tooling and setup | Reused items and any new charges |
| Delivery | Shipping terms, dispatch date and expected receipt |

I request a quote for the quantity I plan to buy and, when useful, the quantity from the previous order. I compare the same specification. If the earlier order qualified for a sample credit or an initial discount, I separate it from the regular price. I ask the supplier to explain any new charge. The [landed cost guide](/blog/compare-packaging-quotes-landed-cost/) gives me a consistent way to compare packing, freight and other delivery costs.

I ask what starts the lead time. An accepted order can still wait for a deposit, material arrival or renewed approval. If the factory quotes a dispatch date, I estimate receipt separately using the shipment plan. I also confirm the quantity tolerance and whether the supplier can deliver in stages. A unit price that depends on a single dispatch may not apply when I need staggered deliveries.

I record how long the quote is valid and what could change before I order. If the supplier offers a lower price for a substitute board or a different case count, I ask for that alternative on its own line. I can then compare the approved specification with the proposal without losing track of which price belongs to each.

## How do I handle a change without losing the approved baseline?

A supplier can propose one adjustment and carry it into later orders by default. I document the scope and approval before it uses the new version.

**I keep the approved specification as the baseline and record each proposed change separately. I confirm the new price, affected items and acceptance checks before releasing the revised order.**

### I make one record the buyer and supplier can both use

I ask for the change in plain terms. If a board grade changes, I want the old grade, the proposed grade, the reason and the date it would enter production. If a new case pack changes the quantity delivered per pallet, I record that too. I ask the affected team to check the change before I approve it. Oracle's procurement documentation describes change orders as a way to revise purchasing documents through a controlled process.[^2] I use the same basic discipline in the order record regardless of which system stores it.

I ask the supplier to confirm which item and revision the final quote covers. I check it against the purchase order before approval. If the order still uses the prior artwork, I make that explicit. If the first delivery under the new terms needs a sample check or a distinct label, I include that instruction and tell the warehouse what to expect.

After receipt, I keep the accepted specification and quote together. I note any difference between what the supplier confirmed and what arrived. The next buyer can then identify the last usable combination and compare a new price without searching an old message thread. I also retain any one-time exceptions so they do not become standing instructions.

## Conclusion

I reuse the last approved specification and sample, then confirm current pricing, tooling and delivery terms before releasing a repeat order.

[^1]: [Esko guidance on structural design files](https://docs.esko.com/docs/en-us/icutlayout/18/userguide/en-us/common/st/concept/co_aboutardfiles.html) explains how structural information differs from artwork.
[^2]: [Oracle Procurement documentation on change orders](https://docs.oracle.com/en/cloud/saas/procurement/26b/oaprc/change-orders.html) describes controlled revisions to purchasing documents.
