# How do I write a component list for a boxed gift set quote?

I can get a price for a gift box and discover that the insert, card and assembly were left out of the quote.

**I give every part its own line, with the quantity per set, specification, revision and supplier responsibility. I show how the parts fit together and define the state in which I need the completed set delivered.**

I build the list around a real gift set. Then I use it to make sure each supplier prices the same work.

## What belongs on the component list?

The main box is easy to remember. Small parts like a pull tab, card or protective sleeve can disappear from the quote.

**I list every packaging piece used in one set and identify the items the buyer supplies. I give each part an item code, description and quantity per finished set.**

### I start with the order in which the customer opens the pack

I open the sample and lay out the parts. I list the outer shell, insert, sleeve, ribbon and printed pieces separately when they are supplied as separate items. If the converter supplies a tray with an attached pull tab, I ask it to show whether the tab is included in the tray price. I list products supplied by the buyer as fit references and mark whether the converter receives them for assembly. That keeps the price for packaging clear when the quote also includes packing services.

| Example part | Quantity per set | Quote instruction |
| --- | ---: | --- |
| Rigid box with lid | 1 | Include approved wrap and finish |
| Fitted tray | 1 | Match the supplied product samples |
| Product cards | 2 | Quote the two artwork versions separately |
| Protective bag | 1 | Confirm who supplies and fits it |

Oracle's bill of material guidance describes recording the components and quantities used in an assembly.[^1] I use the same principle in the [packaging quote checklist](/guides/packaging-quote-checklist/). I also note any extra packaging used for delivery, such as the case for several finished sets. I give the shipping case its own quantity basis so the supplier does not assume there is one per gift box. I confirm the number of completed sets before calculating the purchase quantity of each part.

## Which specifications should I include for each part?

A description such as premium insert leaves each supplier free to choose a different construction. I specify what I need to compare.

**I include the material, dimensions, finish and drawing or artwork revision for each relevant part. I identify the product surfaces and clearances that control the fit.**

### I describe the interface between neighboring parts

I list the tray's outside dimensions and its intended position in the box. I identify the product dimensions and how the product sits in each recess. I specify any opening needed to remove the product. I use the [inside and outside box dimensions guide](/guides/internal-vs-external-box-dimensions/) to keep the measurements clear. If the drawing is provisional, I flag it and ask the supplier to name the dimensions it needs before quoting a firm price.

For the printed parts, I identify the artwork revision and approved surface. I describe where the sleeve ends or where a card sits. I check whether the ribbon runs below the tray or attaches to the lid. These details matter because an extra layer can change the depth available for the product. I send an assembled photo as a reference and identify any point where the drawing and the sample differ.

If a shipping carton is included, I specify the number and orientation of gift sets inside it. FEFCO's design code provides common references for corrugated structures.[^2] I use a code when it describes the case I need and add the dimensions and pack layout separately. I ask the supplier to identify proposed alternatives so each quote shows whether it matches the requested construction.

## How do I specify assembly and delivery?

A box, tray and ribbon can arrive as loose parts or as a ready-to-fill unit. I give the supplier a clear endpoint.

**I state which parts arrive loose, which are fitted, and who packs the products. I ask the supplier to quote assembly, inspection and outbound case packing on the same basis.**

### I write the final state in a way receiving can check

I list the steps I expect the supplier to complete. For example, I may need the tray seated and the ribbon attached, with the gift card delivered in a separate bundle. I ask whether the supplier can protect the decorated surfaces in that condition. I also ask how it will count and label the separate bundles. If I ask the supplier to pack the products too, I specify when it will receive them and which items it is responsible for inspecting.

I request a separate price for optional work. If one quote includes inserting cards and another leaves that job at my warehouse, I account for the time before comparing prices. I compare the quantity of cases and pallets that arrive under each option. A formed box can take more space than a shell delivered flat. I record the actual delivery condition as part of the quote so receiving can verify it.

I ask for an assembled sample that shows the agreed endpoint. I use the [packaging sample types guide](/guides/packaging-sample-types/) to decide whether a structure sample or a production-representative sample is needed. I check that the parts can be handled in the intended sequence without marking the finish or blocking the lid. If the sample needs a change, I update the relevant row rather than rely on a note in a photograph.

## What should I check before accepting the quote?

A supplier can price every component and still assume a different order size or a substitute finish. I compare its reply line by line.

**I reconcile the supplier's quote with the component list and check exclusions, setup charges, quantities and substitutions. I ask the supplier to confirm the final version before ordering.**

### I make missing decisions visible

I compare the quoted quantity for each part with the required number of completed sets. If 500 sets each use two cards, I check that the quote accounts for 1,000 cards in the correct artwork mix. I also check whether the supplier's minimum leaves extra units and who will receive them. If an insert is supplied by another party, I check that it will arrive before the supplier needs it for assembly.

I compare tooling and sample charges separately from the finished unit price. I ask which charges apply to later orders. If a substitute is proposed, I check whether it changes the appearance, fit, or packing work and ask the supplier to price it as an alternative. I do not let a lower price for a different pack stand in for the requested quote. I keep assumptions about freight and case packing in the same record.

I issue the order against the agreed component list and sample. I retain the supplier's item codes beside mine where they differ. I give the warehouse a copy of the final delivery instructions and make sure it knows which pieces to expect loose. When a later order changes a card or ribbon, I can revise that line and check what else it affects.

## Conclusion

I list every component, show how the pieces fit, and compare quotes for the same number of sets in the same delivered condition.

[^2]: [FEFCO code for corrugated packaging designs](https://www.fefco.org/technical-information/fefco-code) provides common references for corrugated structures.
