## 验证

- `python3 tools/validate.py`：全站 2,247 公开页、404、sitemap、内部链接、资源、JSON-LD 与可达性检查。
- `python3 tools/audit-ui.py`：2,248 HTML 页面导航、标题层级、标签、响应式图片、分类搜索范围与共享脚本检查。
- `python3 tools/validate-expansion.py`：原有 1,824 产品的深度内容、十篇采购指南和目录引用完整性。
- `node tools/test-enquiry.mjs`：前端请求上下文、重复提交防护、发送成功/失败、网络故障及附件限制。
- `python3 tools/test-enquiry.py node /tmp/phg-browser/php.cjs`：29 个实际 PHP 端点逻辑场景，假邮件传输；包含新增最简表单通过与缺少需求拒绝。测试环境使用 PHP 8.4 WASM，并通过临时适配器模拟 CLI 的 exit/shutdown 行为；不等同于主机 PHP 端到端邮件验证。
- `tools/test-ux.cjs`：9 类页面 × 360/390/428/768/1024/1440px，共 54 个布局组合；10 次 axe WCAG 2.2 AA 自动检查；移动菜单→磁吸盒→自动关联 RFQ，搜索同义词、分类范围、结构筛选、12 项展开、空态及重置，最简询盘、字段错误、失败保留输入、附件成功与事件隐私检查。邮件响应由测试拦截，没有发送真实邮件。
- 本地 Lighthouse：首页移动端与桌面端 Performance/Accessibility/Best Practices/SEO 均 100；移动 LCP 约 1.21s、CLS 0.002、TBT 0ms；桌面 LCP 约 0.33s、CLS 0.001、TBT 0ms。这是本地模拟导航测量，不是线上真实用户 Core Web Vitals，TBT 也不能代替 INP。
- 本地原始报告和截图：`qa/ux/`（不提交、不部署）。

## 仍需真实运营资料或后续观察的事项

1. 用户确认尚无 GA4 Measurement ID。事件已开放至内存中的 `dataLayer` 与 `packhubglobe:analytics`，没有外部统计接收端，不声称已收集转化。连接统计平台时还需选择实际账户及适用的隐私设置。
2. 产品图片和虚拟品牌概念不作为已交付客户订单证明。具备真实订单与授权材料后可补充正式案例、材料及工艺近摄图。
3. 五秒识别、实际买家任务耗时与满意度需要招募真实用户；自动路径测试不能代替这类研究。没有运行无流量依据的 A/B 实验。
4. 主机邮件最终入箱、真实用户 LCP/INP/CLS、询盘率及搜索表现需上线后分别验证；本次没有发送测试邮件或更改邮箱账户。
5. Git 推送与 Hostinger 发布分开验证。发布证据记录于本次交付消息；不能用推送成功推断所有页面已部署。
