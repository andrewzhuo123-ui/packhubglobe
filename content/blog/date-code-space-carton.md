# How much space should I leave for a date code on a carton?

I can leave enough room for a date in the artwork and still lose a digit when the production line prints beside a fold.

**I reserve room for the longest approved message, the position range I observe on the line, and a clear border. I confirm the area on formed cartons using the intended coder, board and line conditions.**

I size the area from the printed result. That means agreeing on the message and running the actual carton before freezing the artwork.

## How do I measure the longest message I need to print?

A short date in a mockup can hide the length of a batch number or a second line. I measure the longest approved version.

**I list every field the coder must print, including prefixes and separators. I measure the widest and tallest approved layouts using the intended equipment and settings.**

### I ask the line team to supply real message formats

I get the approved fields from the team that owns the label and traceability requirements. I ask for the longest lot identifier, any date prefix, and the number of lines. If the same carton will be filled on several lines, I ask whether line codes have different lengths. I record which field goes first and whether a second language or a different date format changes the layout. A short message from an existing run gives me a useful comparison, but I size the area for the longer approved case.

I measure the result printed by the intended equipment. The printed message can be wider than the one in the designer's mockup. I check letter height, spacing and line pitch on a sample. I keep the actual settings in the record so the line team can reproduce the test. Videojet's overview describes different date coding technologies and applications.[^1] I ask which equipment and settings will be used for this carton before treating the artwork size as final.

I also check the way the printed result identifies the field. If artwork contains a fixed prefix and the line adds only the variable part, I check that the two still read together when placement shifts. If the prefix is printed by the coder, I include it when measuring the longest line. I give the designer both the final message size and a copy of the sample.

## How much extra room should I leave for print movement?

A code can fit exactly inside a blank panel and cross its edge as the carton moves. I measure how far the printed position varies.

**I add the observed left, right, upper and lower placement variation to the message size. I also allow a clear border agreed with the print and line teams.**

### I calculate width and height separately

I choose a reference point on the formed carton, such as an edge that remains visible after closure. I measure the distance from that point to the printed message on several samples. I record the largest shifts on each side rather than using an average. I include normal starts and stops if they affect placement. I ask the line team what other conditions it needs to include before accepting the result. I use the [dieline preparation guide](/guides/prepare-packaging-dielines/) to transfer the approved area to the artwork without losing the reference.

| Illustrative input | Width | Height |
| --- | ---: | ---: |
| Longest printed message | 34 mm | 7 mm |
| Observed travel across both sides | 6 mm | 3 mm |
| Agreed clear border on both sides | 4 mm | 4 mm |
| Example reserved area | 44 mm | 14 mm |

These figures show the calculation. I measure the real message and line movement for my carton. If movement is larger in one direction, I move the artwork area or adjust its boundary to match the observed range. I also check whether the area will still fit on the smallest carton size that shares the layout. I review the dimensions with the line team before the designer places text or decoration beside it.

## Which carton panel should carry the code?

The biggest blank area on the drawing may sit under a flap, face the wrong way on the conveyor, or have a finish the coder cannot mark consistently.

**I choose a panel the coder can reach and the customer can see. I keep the area clear of folds, seams, heavy artwork and finishes that interfere with the chosen marking process.**

### I check the code panel after the carton is closed

I form the carton and put it in the orientation it will have on the line. I look at where the print head or marking equipment can reach it. I check nearby guides, seams and any area that moves when the carton is filled. If the line prints on an open flap, I confirm that the marked area remains visible after closing. I use the [guide to tuck-end cartons](/guides/straight-vs-reverse-tuck-end/) to describe the flap position when I discuss the change with the converter.

I ask which coating, ink or laminate will sit in the code area. A sample printed on plain board may behave differently from a finished carton. Domino's carton coding guidance discusses marking options for different carton applications.[^2] I ask the equipment supplier which process suits the actual surface and request a trial on the approved board and finish. I check legibility and durability after normal packing and handling.

I also stand the finished carton on a shelf or display tray. I confirm that the user can locate the code without opening the pack if that is a requirement. If two panels are possible, I ask the line team which one gives more consistent placement. I compare that with the reading position and choose an area that meets both needs.

## What should I check before approving the reserved area?

A clean proof can show the proposed space. I still need evidence that the line can fill it consistently and that the printed code stays readable.

**I run representative cartons through the intended coding setup. I inspect the longest message, position extremes, contrast and durability, and retain the accepted samples with the artwork revision.**

### I approve the drawing and the coded pack together

I start with the longest approved message on the smallest relevant panel. I check the first and last characters, both lines if present, and the space around them. I compare several packs under representative line conditions. If the code drifts toward a fold, I ask the team to identify what changed on the line before I add more space. A larger area can absorb normal movement. It cannot correct every problem with a carton that is fed unevenly.

I check the mark after the normal handling interval. I look for smearing, missing characters, low contrast or a mark that has transferred to a nearby surface. I check the date and lot information against the job setup. I use the [packaging print proof guide](/guides/packaging-print-proof/) to keep the review tied to the exact board and artwork, then add the coded samples and settings to the approval record.

I keep the area visible in the production drawing and specify when a new check is needed. Changes to carton size, finish, message format or coding equipment can affect the result. When one changes, I compare the first samples against the agreed criteria before approving the revised setup. The warehouse and quality team can then use the same reference when checking later batches.

## Conclusion

I size the area from the longest printed message and measured placement variation, then approve it on the finished carton under normal line conditions.
